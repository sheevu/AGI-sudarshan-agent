# Vyapaar AGI Static Frontend

This repository is a deployment-ready static site for the Vyapaar AGI infographic.

## Files
- `index.html`: default entry point.
- `flow.html`: main infographic page.
- `main1.html`: compatibility redirect to `flow.html`.

## Local run
Use any static file server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment
This project can be deployed on any static hosting platform (GitHub Pages, Netlify, Vercel static, Firebase Hosting).
